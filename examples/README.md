# Examples

Generated by `tools/gen-catalog.py` from each example's README front matter — do not edit.
Every example targets the NUCLEO-G474RE (STM32G474RET6, on-board ST-LINK/V3E) and builds with
`cmake --preset nucleo-debug && cmake --build --preset nucleo-debug`.
There is no simulator for the STM32G4: pure logic is host-tested, the rest needs the board.
