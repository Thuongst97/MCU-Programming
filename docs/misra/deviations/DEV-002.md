# DEV-002: Com signal values passed as `void *`

| Field | Value |
|---|---|
| Rule | MISRA C:2012 Rule 11.5 (advisory) |
| Scope | `autosar/services/com/Com.c`: `Com_SendSignal`, `Com_ReceiveSignal` |
| Raised by / date | MCU Academy authors, Phase 6 |
| Approved by / date | self-review, Phase 6 |

## Why the rule cannot be followed here
The Com API takes the signal value as an untyped pointer, so one function serves every signal
type. The implementation has to convert it to the configured type.

## Why it is safe
Com-lite supports only signals of 1 to 8 bits, and the RTE always passes a `uint8` or `boolean`
object, both one byte. The configuration tables are the single source for the size.

## How it is marked in code
`// cppcheck-suppress misra-c2012-11.5 ; DEV-002` on the line before each conversion.

## Review
When Com-lite supports wider signals.
