# DEV-005: name pasting in the OSEK task and alarm macros

| Field | Value |
|---|---|
| Rule | MISRA C:2012 Rule 20.10 (advisory) |
| Scope | `autosar/os_shim/Os.h`: `TASK()`, `ALARMCALLBACK()`, `DeclareTask()` |
| Raised by / date | MCU Academy authors, Phase 6 |
| Approved by / date | self-review, Phase 6 |

## Why the rule cannot be followed here
OSEK/AUTOSAR OS defines `TASK(Name)` as the way to write a task body; the OS must turn the name
into a function name, which needs the `##` operator.

## Why it is safe
The macros paste a fixed prefix to an identifier; the result is checked by the compiler like any
function name.

## How it is marked in code
Scoped in `tools/run-misra.py` (SCOPED) to `Os.h`.

## Review
When the shim is replaced by a real AUTOSAR OS.
