# DEV-003: task index passed through the FreeRTOS task parameter

| Field | Value |
|---|---|
| Rule | MISRA C:2012 Rule 11.6 (required) |
| Scope | `autosar/os_shim/Os.c`: `Os_TaskEntry` |
| Raised by / date | MCU Academy authors, Phase 6 |
| Approved by / date | self-review, Phase 6 |

## Why the rule cannot be followed here
FreeRTOS hands a task one `void *` parameter. The OS shim uses one entry function for every task
and passes the task's index, converted through `uintptr_t`, so no table of wrapper functions is
needed.

## Why it is safe
The value is created from a `TaskType` (0..OS_NUM_TASKS-1) in `StartOS` and converted back to
`TaskType` in the same file; it is never dereferenced.

## How it is marked in code
`// cppcheck-suppress misra-c2012-11.6 ; DEV-003`.

## Review
When the shim is replaced by a real AUTOSAR OS (the deviation then disappears with it).
