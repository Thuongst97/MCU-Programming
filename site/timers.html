Timers, PWM and Input Capture

Hardware timers count clock cycles while the CPU does other work. With them you get exact periods, PWM signals that dim LEDs or drive motors, and precise measurements of incoming signals. The STM32G474 has many: advanced timers (TIM1, TIM8, TIM20), general-purpose timers (TIM2–TIM5, TIM15–TIM17), basic timers and a high-resolution timer; this module uses TIM3 and TIM2, which at the course's clock setup run at 170 MHz.

7.1Prescaler, ARR and update events

A general-purpose timer is a counter with a 16-bit prescaler in front of it (RM0440, TIM2/TIM3/TIM4/TIM5). TIM3 and TIM4 count with 16 bits; TIM2 and TIM5 have 32-bit counters:

  • The prescaler PSC divides the timer clock by PSC + 1. Each resulting tick advances the counter CNT by one.
  • When CNT reaches the auto-reload value ARR, it goes back to 0 and raises an update event (UEV), which can trigger an interrupt or DMA request.
fupdate = fTIM ÷ ((PSC + 1) × (ARR + 1))

For 1 kHz from a 170 MHz timer clock: 170 000 000 ÷ 1000 = 170 000 = (PSC + 1) × (ARR + 1). PSC = 169 and ARR = 999 gives 1 µs ticks and 1000 steps per period, which is handy for PWM. On a 16-bit timer each factor must be ≤ 65 536. Try other values:

Analogy

The prescaler is a gear that turns the fast motor shaft into slow, regular steps; the counter is a clock face with ARR + 1 positions. Each time the hand passes 12 o'clock, a bell rings: the update event.

7.2The ×2 timer clock rule

Which clock reaches the timer? TIM2–TIM7 are on APB1; TIM1, TIM8, TIM15–17 and TIM20 on APB2. The rule (RM0440, RCC): if the APB prescaler is 1, the timer clock equals the bus clock; otherwise it is twice the bus clock.

7.3PWM with output compare

In PWM mode 1, each channel compares the counter with its capture/compare register CCRx: the output is active while CNT < CCRx and inactive for the rest of the period. The period is set by ARR, the duty cycle by CCRx ÷ (ARR + 1).

Why preload matters

With OC1PE and ARPE set, new CCR and ARR values wait in a shadow register until the next update event. Without preload, writing a smaller CCR just after the counter passed it would leave the output high for a whole extra period: a visible glitch on a dimmed LED or a jolt on a motor.

7.5Input capture

In input capture, an edge on a timer input copies the running counter into CCRx. The difference between two captures is a period in timer ticks. The general-purpose timers have a PWM input mode that measures period and high time in one go: channel 1 captures on the rising edge, channel 2 on the falling edge of the same pin, and the slave controller resets the counter on each rising edge (RM0440, TIM2/TIM3/TIM4/TIM5). Example 03 uses TIM2, whose 32-bit counter cannot overflow between two edges of any signal it is likely to see.

Pin conflicts

A pin can only have one alternate function at a time. PA5 carries TIM2_CH1 but also drives LD2; PB3 (TIM2_CH2) is the debugger's SWO line; PA11/PA12 are FDCAN1 in this course. The table above came from python3 tools/check-pins.py --signal TIM3_CH, which reads ST's pin database.
