Timers, PWM and Input Capture

Hardware timers count clock cycles while the CPU does other work. With them you get exact periods, PWM signals that dim LEDs or drive motors, and precise measurements of incoming signals. The F103 has one advanced timer (TIM1) and three general-purpose timers (TIM2–TIM4); this module uses TIM3 and TIM2.

7.1Prescaler, ARR and update events

A general-purpose timer is a 16-bit counter with a prescaler in front of it (RM0008 §15.3):

  • The prescaler PSC divides the timer clock by PSC + 1. Each resulting tick advances the counter CNT by one.
  • When CNT reaches the auto-reload value ARR, it goes back to 0 and raises an update event (UEV), which can trigger an interrupt or DMA request.
fupdate = fTIM ÷ ((PSC + 1) × (ARR + 1))

For 1 kHz from a 72 MHz timer clock: 72 000 000 ÷ 1000 = 72 000 = (PSC + 1) × (ARR + 1). PSC = 71 and ARR = 999 gives 1 µs ticks and 1000 steps per period, which is handy for PWM. Both registers are 16 bits, so each factor must be ≤ 65 536. Try other values:

Analogy

The prescaler is a gear that turns the fast motor shaft into slow, regular steps; the counter is a clock face with ARR + 1 positions. Each time the hand passes 12 o'clock, a bell rings: the update event.

7.2The ×2 timer clock rule

Which clock reaches the timer? TIM2–TIM4 are on APB1, TIM1 on APB2. The rule (RM0008 §7.2): if the APB prescaler is 1, the timer clock equals the bus clock; otherwise it is twice the bus clock.

7.3PWM with output compare

In PWM mode 1, each channel compares the counter with its capture/compare register CCRx: the output is active while CNT < CCRx and inactive for the rest of the period. The period is set by ARR, the duty cycle by CCRx ÷ (ARR + 1).

Why preload matters

With OC1PE and ARPE set, new CCR and ARR values wait in a shadow register until the next update event. Without preload, writing a smaller CCR just after the counter passed it would leave the output high for a whole extra period: a visible glitch on a dimmed LED or a jolt on a motor.

7.5Input capture

In input capture, an edge on a timer input copies the running counter into CCRx. The difference between two captures is a period in timer ticks. The F1 timers have a PWM input mode that measures period and high time in one go: channel 1 captures on the rising edge, channel 2 on the falling edge of the same pin, and the slave controller resets the counter on each rising edge (RM0008 §15.3.6).
