CAN and CAN FD with FDCAN (and LIN in Theory)

CAN is the backbone of in-vehicle networks: dozens of ECUs share one twisted pair, any node can talk, the most important message always wins, and a broken node takes itself off the bus. This module goes from the voltages on the wire to the G4's FDCAN registers and its message RAM, then connects two NUCLEO boards with classic and CAN FD frames. LIN is covered in theory.

12.1Physical layer and transceivers

CAN uses two wires, CAN_H and CAN_L, and reads the difference between them, so noise that hits both wires equally cancels out (ISO 11898-2). There are two bus states:

  • Recessive (logic 1): nobody drives; both wires float at about 2.5 V, difference ≈ 0 V.
  • Dominant (logic 0): a transceiver pulls CAN_H up to about 3.5 V and CAN_L down to about 1.5 V, difference ≈ 2 V.

Dominant always beats recessive: if one node sends 0 and another 1, the bus reads 0. This "wired-AND" is what makes arbitration work. The MCU never touches the bus directly: a transceiver converts between the controller's TX/RX logic pins (FDCAN1_TX on PA12, FDCAN1_RX on PA11) and the differential pair. The NUCLEO has none: you add a 3.3 V transceiver module, and for CAN FD it must be rated for the data-phase bit rate you use (many cheap SN65HVD230 modules are specified for classic CAN up to 1 Mbit/s only, SLOS346). A 120 Ω resistor at each end of the bus absorbs reflections.

Analogy

A room full of people with one rule: anyone may shout "no!" (dominant), and silence means "yes" (recessive). If even one person shouts, everyone hears "no". Nobody can be talked over by silence.

12.2The CAN frame

A classic CAN data frame with an 11-bit identifier (ISO 11898-1). Change the ID and the data: the CRC is computed and stuff bits are inserted live. After five equal bits in a row, the sender inserts one opposite bit (red markers) so that receivers always see edges to stay synchronised.

12.3Arbitration and errors

When several nodes start at the same moment, they all send their identifier bit by bit and listen at the same time. A node that sends recessive (1) but reads dominant (0) has lost and stops sending at once, without destroying the winner's frame. The lowest identifier wins. Enter up to three IDs:

Errors are handled the same collective way: every node checks every frame, and a node that detects an error destroys the frame with an error frame (six dominant bits that break the stuffing rule), so everyone discards it and the sender retries. 12.4Bit timing calculator

There is no clock wire, so every node divides each bit into time quanta (tq) and resynchronises on edges. A bit is 1 tq of sync segment, TSEG1 tq before the sample point and TSEG2 tq after it; a quantum lasts BRP periods of the FDCAN kernel clock. The G4 holds the arbitration-phase timing in FDCAN_NBTP and the CAN FD data-phase timing in FDCAN_DBTP, each field storing its value minus one (RM0440, FDCAN). All nodes on one bus must use the same bit rate and similar sample points; 87.5 % is a common target in automotive networks.

12.5The FDCAN peripheral

The STM32G474 has three FDCAN controllers (RM0440, FDCAN; ST's introduction is AN5348). They implement classic CAN and CAN FD (ISO 11898-1:2015) and are built around a message RAM: frames to send and frames received are not in registers but in a shared block of SRAM that the controller reads and writes on its own. Three things set them apart from older STM32 CAN controllers:

  • A kernel clock. FDCAN counts time quanta in its own clock, chosen in RCC_CCIPR.FDCANSEL. The reset value selects HSE, which the course does not start, so example 11 selects PCLK1 (170 MHz) first.
  • INIT and CCE. After reset CCCR.INIT = 1: the controller is off the bus. Setting CCE as well unlocks the protected registers (bit timing, test modes, RAM layout). Clearing INIT joins the bus after 11 recessive bits on FDCAN1_RX, which is why a missing transceiver (RX floating low) keeps it waiting.
  • Bus-off is not automatic. On bus-off the controller sets INIT itself and stays off the bus until software clears it; it then waits for 129 × 11 recessive bits before taking part again.

12.6Message RAM and filters

On the G4 the message RAM has a fixed layout: each FDCAN instance owns 0x350 bytes starting at SRAMCAN_BASE, divided into standard and extended ID filters, two RX FIFOs of 3 elements, a TX event FIFO and 3 TX buffers (RM0440, FDCAN message RAM). Every RX and TX element is 18 words: two header words (identifier, DLC, FDF and BRS bits) and up to 64 data bytes. Hover a block:

To send, the driver writes an element at the TX FIFO's put index (TXFQS.TFQPI) and sets the matching bit in TXBAR; the controller arbitrates and retries by itself. To receive, it reads the element at RX FIFO 0's get index (RXF0S.F0GI) and acknowledges it in RXF0A, which frees the slot. Filters. A busy bus carries hundreds of message IDs, and an ECU needs a few of them. Acceptance filters drop the rest in hardware. The G4's filters are elements in the same message RAM (up to 28 standard-ID filters per instance). 12.7Two nodes on a real bus

Each node needs a transceiver; CAN_H to CAN_H, CAN_L to CAN_L over a twisted pair, a common ground, and 120 Ω at both ends (many modules carry one; check yours, and never fit more than two on one bus).

Before touching the bus, each node tests itself in internal loopback mode: CCCR.TEST + MON and TEST.LBCK connect the transmitter to the receiver inside the chip, and nothing reaches the pins, so this works without a transceiver or a second node. The self-test even sends a 20-byte CAN FD frame:

12.8CAN FD in practice

CAN FD (flexible data-rate, ISO 11898-1:2015) keeps arbitration at the classic bit rate, then may switch to a faster rate for the data phase and carries up to 64 data bytes. The G474's FDCAN supports it once you allow it: CCCR.FDOE enables FD frames, CCCR.BRSE the bit-rate switch, and DBTP holds the data-phase timing. Per frame, the TX element's FDF bit makes it an FD frame and BRS asks for the faster data phase.

A controller that only knows classic CAN sees an FD frame's reserved bit set and answers with an error frame, every time. A bus mixes FD frames only if every node on it is FD-capable or FD-tolerant, and every transceiver is rated for the data-phase rate. 12.10LIN in theory

LIN is CAN's cheap little sibling for simple functions (switch panels, mirror motors, rain sensors). It is a single wire at up to 20 kbit/s with one master that runs a fixed schedule table and polls slaves; slaves never speak unasked, so there is no arbitration. A LIN node is often just a UART plus a transceiver, which is why the G4's USARTs have a LIN mode (module 08).
