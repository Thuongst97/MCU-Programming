SPI and a W25Qxx Flash

SPI is the simple, fast one: a clock, one data line in each direction, and a chip-select per device. No addresses, no acknowledges, tens of megahertz. This module covers the four SPI modes, the F1 SPI peripheral, chip-select discipline, and a W25Qxx NOR flash, including reading it with DMA.

11.1SPI modes CPOL/CPHA

Four signals: SCK (clock from the master), MOSI (master out, slave in), MISO (master in, slave out) and CS or NSS (chip select, active low). Every clock pulse moves one bit in each direction at the same time: SPI is a pair of shift registers connected in a ring.

Two settings must match the slave: CPOL (clock idle level) and CPHA (sample on the first or second edge). Together they form modes 0–3. Pick a mode; green lines mark the sampling edges:

11.2The F1 SPI peripheral

The F1's SPI is configured mostly in SPI_CR1 (RM0008 §25.5.1). SPI1 sits on APB2 and can run at up to 18 MHz (fPCLK2 ÷ 4) in master mode on this part (DS5319 SPI characteristics); example 07 uses ÷ 16 = 4.5 MHz, which is comfortable over jumper wires.

11.3Chip select discipline

Chip select frames a command. For most SPI devices a falling CS starts a new command and a rising CS ends it, and some commands (erase, program) only start executing when CS rises. Three rules:

  1. Drive CS from a GPIO under software control (SSM = 1, SSI = 1), so one transaction can span many bytes. The hardware NSS output of the F1 is awkward for multi-byte transactions.
  2. Wait for BSY = 0 before raising CS. TXE only means the data register is free; the last byte may still be shifting out.
  3. Set CS high before configuring it as an output, so the device never sees a spurious select during start-up.
⚠️
One CS per device, never two low at once

Several devices can share SCK, MOSI and MISO, but only the selected one may drive MISO. Two selected devices drive MISO against each other.

11.4Talking to a W25Qxx

A W25Qxx is a NOR flash: you can read any byte at any time, but you can only change bits from 1 to 0 by programming, and back to 1 only by erasing a whole 4 KB sector. Every erase or program must be preceded by Write Enable and followed by polling the BUSY bit (W25Q datasheet).

11.5SPI with DMA

Reading a whole page byte by byte keeps the CPU busy for every byte. With DMA, two channels do it: channel 3 feeds dummy bytes into DR (each one clocks a byte in), and channel 2 copies every received byte into the buffer. The receive channel gets the higher priority so it never falls behind.
